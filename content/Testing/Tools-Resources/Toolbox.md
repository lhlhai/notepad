# 🛠️ The Ultimate Tester's Toolbox: Work 3x Faster

Danh sách các công cụ và tài nguyên "tinh túy" giúp bạn tối ưu hóa quy trình làm việc và xử lý các tác vụ khó một cách dễ dàng.

## 1. Trình duyệt Extensions (Chrome/Edge)
Những trợ thủ đắc lực nằm ngay trên thanh công cụ của bạn.

| Công cụ | Công dụng chính | Tại sao nên dùng? |
| :--- | :--- | :--- |
| **SelectorHub** | Lấy XPath/CSS Selector | Chính xác nhất, hỗ trợ cả Shadow DOM và iframe. |
| **Fake Filler** | Điền form tự động | Tiết kiệm hàng giờ nhập liệu thủ công mỗi ngày. |
| **JSON Viewer** | Định dạng file JSON | Giúp đọc cấu trúc API Response cực kỳ dễ dàng. |
| **Clear Cache** | Xóa nhanh dữ liệu duyệt web | Đảm bảo bạn đang test trên phiên bản code mới nhất. |
| **Wappalyzer** | Kiểm tra công nghệ website | Biết được web dùng React, Vue hay PHP để có chiến lược test phù hợp. |

---

## 2. Công cụ Web hữu ích (Online Tools)
Không cần cài đặt, truy cập và sử dụng ngay lập tức.

- **[✨ Interactive Toolbox](./Interactive-Toolbox.md):** **Chạy trực tiếp** UUID, Password, JSON, JWT, Base64... ngay trên trang này mà không cần rời khỏi Notepad.
- **[Regex101](https://regex101.com/):** Kiểm tra và giải thích các biểu thức chính quy (Regex). Cực kỳ hữu ích khi test validation field.
- **[JWT.io](https://jwt.io/):** Giải mã các token xác thực để kiểm tra thông tin bên trong (Role, Expire time).
- **[Postman/Insomnia](https://www.postman.com/):** "Ông vua" trong làng kiểm thử API.
- **[ConvertCSV](https://www.convertcsv.com/):** Chuyển đổi qua lại giữa JSON, CSV, Excel để chuẩn bị dữ liệu kiểm thử.

---

## 3. Desktop Apps chuyên dụng
Dành cho các tác vụ chuyên sâu và yêu cầu hiệu năng cao.

- **Charles Proxy / Fiddler:** Đánh chặn (Intercept) và chỉnh sửa request/response giữa Client và Server. Dùng để test các case lỗi phía Server hoặc giả lập mạng yếu.
- **DBeaver:** Công cụ quản lý Database đa năng, hỗ trợ hầu hết các loại DB hiện nay.
- **Snagit / ShareX:** Chụp ảnh và quay video màn hình chuyên nghiệp, hỗ trợ vẽ mũi tên, ghi chú cực nhanh để log bug.
