# 📋 Manual Testing Hub

Manual Testing là nền tảng của mọi hoạt động đảm bảo chất lượng. Mục này cung cấp các kiến thức về tư duy, kỹ thuật và các biểu mẫu thực tế để bạn thực hiện kiểm thử thủ công một cách chuyên nghiệp.

## 📂 Tài liệu trong mục này
- **[Manual Testing Theory](Theory.md)**: Các khái niệm cốt lõi, quy trình STLC và các cấp độ kiểm thử.
- **[Professional Templates](Templates.md)**: Tổng hợp mẫu Test Case, Bug Report và Test Summary Report.
- **[Manual Cheatsheet](Cheatsheet.md)**: Các kỹ thuật thiết kế test case nhanh (Phân vùng tương đương, Phân tích giá trị biên,...) và Smoke Test checklist.

## 📅 Daily Tasks cho Manual Tester
- [ ] **Review Requirements:** Đọc kỹ tài liệu mô tả tính năng mới để tìm ra các điểm chưa rõ ràng.
- [ ] **Test Case Design:** Viết các kịch bản kiểm thử dựa trên yêu cầu, đảm bảo độ bao phủ (coverage).
- [ ] **Test Execution:** Thực hiện test trên các môi trường khác nhau (Web, Mobile, Browsers).
- [ ] **Bug Reporting:** Ghi lại các lỗi phát hiện được với đầy đủ thông tin tái dựng.
- [ ] **Regression Check:** Kiểm tra lại các tính năng cũ sau khi có code mới được merge.
