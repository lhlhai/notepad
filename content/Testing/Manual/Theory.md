# 📖 Manual Testing: Core Theory

Lý thuyết cốt lõi về kiểm thử thủ công, nền tảng cho mọi Tester chuyên nghiệp.

## 1. Quy trình STLC (Software Testing Life Cycle)
Quy trình chuẩn để đảm bảo chất lượng phần mềm:
1. **Requirement Analysis:** Phân tích spec, làm rõ các điểm chưa rõ với BA/PO.
2. **Test Planning:** Xác định scope, resource, schedule.
3. **Test Case Development:** Viết kịch bản chi tiết.
4. **Environment Setup:** Chuẩn bị data, server, thiết bị.
5. **Test Execution:** Chạy test, log bug.
6. **Test Closure:** Tổng kết, đánh giá chất lượng build.

## 2. Các cấp độ kiểm thử (Testing Levels)
- **Unit Test:** Kiểm tra hàm/module (thường do Dev).
- **Integration Test:** Kiểm tra sự kết nối giữa các module.
- **System Test:** Kiểm tra toàn bộ hệ thống (End-to-End).
- **UAT (User Acceptance Test):** Kiểm tra mức độ chấp nhận của người dùng cuối.

## 3. Các loại kiểm thử phổ biến
- **Functional Testing:** Kiểm tra tính năng chạy đúng spec không.
- **Non-functional Testing:** Kiểm tra hiệu năng, bảo mật, độ tin cậy.
- **Regression Testing:** Kiểm tra lại các phần cũ sau khi sửa code mới.
- **Smoke Testing:** Kiểm tra nhanh các tính năng "sống còn".
