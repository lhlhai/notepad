# 🧪 Tester: Manual, Automation & API Mastery

Chào mừng bạn đến với trung tâm kiến thức về Kiểm thử phần mềm. Đây là bộ tài liệu được thiết kế theo phong cách **Pro Max**, tập trung vào tính thực tiễn, cung cấp đầy đủ từ lý thuyết cốt lõi đến các bộ công cụ (Cheatsheets) và mẫu tài liệu (Templates) dùng hàng ngày.

## 📂 Cấu trúc danh mục

### 1. [Manual Testing](./Manual/Theory.md)
Tập trung vào tư duy kiểm thử, kỹ thuật thiết kế test case và quy trình quản lý lỗi chuyên nghiệp.
- **[Theory](./Manual/Theory.md)**: STLC, các cấp độ và loại kiểm thử.
- **[Cheatsheet](./Manual/Cheatsheet.md)**: Các kỹ thuật BVA, EP và dữ liệu kiểm thử biên.
- **[Templates](./Manual/Templates.md)**: Mẫu Test Case, Bug Report và Test Report chuẩn industry.

### 2. [Automation Testing](./Automation/Theory.md)
Hướng dẫn xây dựng hệ thống tự động hóa bền vững với các công cụ hiện đại.
- **[Theory](./Automation/Theory.md)**: Kim tự tháp kiểm thử và chiến lược tự động hóa.
- **[Cheatsheet](./Automation/Cheatsheet.md)**: Snippets cho Playwright và Pytest.
- **[Frameworks](./Automation/Frameworks.md)**: Kiến trúc Page Object Model (POM) và tích hợp CI/CD.

### 3. [API Testing](./API/Theory.md)
Làm chủ việc kiểm thử các tầng logic nghiệp vụ và bảo mật hệ thống.
- **[Theory](./API/Theory.md)**: HTTP Methods, Request/Response structure.
- **[Cheatsheet](./API/Cheatsheet.md)**: Status Codes và Python Requests snippets.
- **[Security](./API/Security.md)**: OWASP API Top 10 và Checklist bảo mật.

---
