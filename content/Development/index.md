# 🛠 Development for Testers Hub

Kỹ năng lập trình không chỉ dành cho Developer. Đối với QA/Tester, lập trình giúp tự động hóa các tác vụ lặp đi lặp lại và xây dựng các công cụ hỗ trợ kiểm thử mạnh mẽ.

## 📂 Tài liệu học tập

| Chủ đề | Nội dung chính |
| :--- | :--- |
| **Python Testing** | **[Python Testing](Python-Testing.md)**: Sử dụng Python để viết script, xử lý dữ liệu và tạo unit test. |
| **Web Automation** | **[Web Automation](Web-Automation.md)**: Kỹ thuật tương tác với trình duyệt, xử lý các phần tử web phức tạp. |
| **MCP Testing** | **[MCP Testing](MCP-Testing.md)**: Tìm hiểu về Model Context Protocol và cách ứng dụng trong kiểm thử hiện đại. |

## 📅 Daily Coding Tasks cho QA

*   **Viết Script hỗ trợ (Utility Scripts):** Tạo các công cụ nhỏ bằng Python để convert dữ liệu, quét link hỏng (broken links) hoặc tạo hàng loạt account test.
*   **Code Review:** Tham gia xem xét code automation của đồng nghiệp để đảm bảo tính tối ưu và dễ đọc.
*   **Debug mã nguồn:** Phối hợp với Developer để đọc hiểu code ứng dụng, từ đó xác định nguyên nhân gốc rễ (Root Cause) của bug nhanh hơn.
