## 🛠️ Daily DevOps Tasks cho Tester

Trong kỷ nguyên hiện đại, Tester cần nắm vững các kỹ năng "Ops" để chủ động trong công việc:

1.  **Giám sát Pipeline:** Theo dõi trạng thái các job chạy test tự động trên Jenkins hoặc ADO. Nếu job fail, cần phân tích log để biết lỗi do môi trường, do code hay do script test.
2.  **Quản lý Branch:** Thực hiện merge code, giải quyết xung đột (conflict) khi làm việc nhóm trên các bộ script automation.
3.  **Cấu hình Môi trường:** Tùy chỉnh các biến môi trường (Environment Variables) hoặc file config để chạy test trên các server khác nhau.
